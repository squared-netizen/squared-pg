## Purpose

boundary.

## Content

`engine/` contains the native C++ implementation of functionality belonging to
the generator/runtime support layer rather than to generated application code.

It MUST be treated as a distinct component with its own:

- `CMakeLists.txt`
- `AGENTS.md`
- `README.md`

Public C++ headers belong under `engine/include/`.
Implementation files belong under `engine/src/`.

The public/private boundary MUST be explicit. Implementation headers MUST NOT be
exposed as public API merely for convenience.
