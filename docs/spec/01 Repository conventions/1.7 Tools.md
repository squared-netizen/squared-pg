# 1.7 Tools

> [!info] Navigation
> Index: [[Specification Index]] · Parent: [[1 Repository conventions]]
> Prev: [[1.6 Third-party dependencies]] · Next: [[1.8 Documentation]]

## Purpose

Defines the role and limits of `tools/`.

## Outline

- [x] scope
- [x] prohibition on shadow generator logic

## Content

`tools/` contains repository-maintenance and developer-facing tooling.

Tools MUST NOT become an undocumented second implementation of generator logic.
Generator behaviour belongs in the generator architecture itself.

Current examples:

```text
tools/clang-check.fish
tools/lua-check.fish
```
