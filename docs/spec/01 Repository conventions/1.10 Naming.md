## Content

Names MUST communicate architectural ownership.

In particular:

- C++ types use the project's established C++ naming convention.
- Lua modules use Lua module naming conventions.
- Resource directories use lowercase, stable identifiers.
- Version identifiers MUST be explicit where multiple versions may coexist.
- Files MUST NOT encode transient machine-specific paths.
