# 1.13 Repository invariant

> [!info] Navigation
> Index: [[Specification Index]] · Parent: [[1 Repository conventions]]
> Prev: [[1.12 Development instructions]]

## Purpose

The offline-first guarantee.

## Outline

- [x] offline usability requirement
- [x] scope of the guarantee

## Content

The repository MUST remain usable as an offline source checkout.

A clean checkout plus the declared vendored dependencies MUST provide everything
required to inspect, build, test, and develop `squared-pg`, subject only to
explicitly documented host-tool requirements.
