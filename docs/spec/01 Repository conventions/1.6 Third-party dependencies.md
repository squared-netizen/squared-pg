## Content

`third-party/` is the repository location for vendored dependencies required to
build or run the generator offline.

> [!warning] Status
> The `third-party/` directory exists on disk but currently contains only a
> placeholder (`.gitkeep`). None of the dependencies below are vendored yet. The
> list is the intended set and governs what the directory is for, not what it
> currently holds.

Intended dependency set:

| Dependency | Version |
|---|---|
| Lua | 5.4.8 |
| LuaFileSystem | 1.8.0 |
| Penlight | 1.14.0 |
| LDoc | 1.5.0 |
| miniz | 3.1.2 |
| yyjson | 0.12.0 |

Downloaded source archives and integrity information belong under
`third-party/cache/`.

Vendored source trees MUST remain versioned and identifiable.

Third-party code MUST NOT be modified unless the modification is explicitly
required by `squared-pg` and documented.
