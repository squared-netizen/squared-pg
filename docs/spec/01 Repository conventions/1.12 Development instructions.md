## Purpose

## Outline

- [x] role of `AGENTS.md`
- [x] nesting and override behaviour
- [x] obligation to inspect

## Content

`AGENTS.md` files define local development constraints.

A nested `AGENTS.md` overrides or supplements the applicable parent instructions
for its directory.

Agents MUST inspect applicable `AGENTS.md` files before modifying code.
