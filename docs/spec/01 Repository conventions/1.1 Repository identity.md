## Purpose

- [x] top-level directory division

## Content

`squared-pg` is the canonical offline-first project generator for applications
built on the Squared framework.

The repository is divided into:

```text
engine/
lua/
third-party/
tools/
docs/
```

The root contains the project-wide build configuration and project documentation.

Two additional top-level entries are present in the repository but are not
core engine divisions in their own right:

- `sqcart/` — a nested, self-contained companion project (its own build and test
  harness) used to drive `squared-pg`'s development.
- `docs/spec/` — the functional specification vault, part of `docs/` (see
  [[1.8 Documentation]]).

The shared resource tree `resources/` described in [[1.5 Resources]] is planned
but not yet provisioned on disk.
