# squared-pg functional specification

This directory is an Obsidian vault. Open `squared-pg/docs/spec/` as the vault
root and start at **Specification Index**.

It can also be read as plain Markdown — every link is a `[[wikilink]]` matching a
filename in this tree.

```
Specification Index.md          entry point
_meta/                          conventions, glossary, decisions, open questions, status
01 Repository conventions/      §1.1 – §1.13
02 Generator architecture/      §2.1 – §2.16
```

Open `docs/` rather than `docs/spec/` as the vault root only if you want
`docs/edu/` visible too; note that `docs/edu/Glossary.md` and this tree's
`_meta/Spec glossary.md` are deliberately named differently to avoid a link
collision if you do.
