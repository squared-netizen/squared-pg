# {{PROJECT_TITLE}}

Offline-first Android ARM64 application generated by `squared-pg` using its
SDL2 frontend template.

## Start here

```sh
lua5.4 tools/build.lua
```

The default build uses Gradle's offline mode. Permit one dependency download
with:

```sh
lua5.4 tools/build.lua --online-once
```

See [[docs/Building|Building]] and
[[docs/GitHub-Actions|GitHub Actions]]. The scripting contract is documented
in [[docs/Scripting|Lua Scripting]] and [[docs/Plugins|Lua Plug-ins]].
The generated SDL adapter and developer-owned C++ source boundary are
documented in [[docs/Application|Application Boundary]].
Generate the Lua, C++, and Java API references with `squared-pg docs`; see
[[docs/API|API Reference]].
The OpenGL ES graphics foundation is described in
[[docs/Graphics2D|Graphics2D]], and [[docs/Scene2D|Scene2D]].
Strict native JSON parsing and deterministic writing are described in
[[docs/Data|Data and JSON]].
Application, simulation, and editor-preview clocks are described in
[[docs/Time|Time Domains]].
Queued and delayed Telegram/Telegraph routing is described in
[[docs/Messaging|Telegram Messaging]].
The generated atlas-backed status square begins blue and toggles green when
touched, making process survival across background/foreground testing visible.
The smaller square beneath it is driven by delayed directed Telegrams,
alternates magenta and cyan once per application-time second, and freezes
while the app is backgrounded.
A tiny square beside it begins red and turns green after a
`TelegramProvider` supplies fresh JSON state to the new application subscriber
through the ordinary message queue.
A second tiny square is green after a delayed Telegram survives deterministic
JSON snapshot, strict parsing, transactional restoration, and delivery; orange
indicates failure.
The primary diagnostic is now a text report containing explicit status values
and a compact JSON Telegram dump. The same report is written natively to
`/sdcard/Download/{{PROJECT_ID}}-diagnostics.log` when the project is generated
with `--manage-all-files` and the corresponding Android special access is
granted.

{{MANAGE_ALL_FILES_WARNING}}

The adjacent panel renders JSON-provided text with SDL_ttf after a strict,
deterministic JSON round-trip. A stage-specific color remains visible if text
cannot be displayed; see [[docs/Data|Data and JSON]].

## Application boundaries

- Generated SDL adapter: `app/src/main/cpp/platform/`
- Developer C++ application: `app/src/main/cpp/application/`
- Developer C++ headers: `app/src/main/cpp/application/include/`
- Composed Squared module APIs and sources: `modules/`
- Trusted Lua runtime: `app/src/main/assets/lua/runtime/`
- Application plug-ins: `app/src/main/assets/lua/plugins/`
- Graphics and atlas assets: `app/src/main/assets/graphics/`
- Diagnostic configuration: `app/src/main/assets/diagnostics/`
- Bundled diagnostic font: `app/src/main/assets/fonts/`
- Private Lua 5.4.8 source: `third_party/lua-5.4.8/`
- Squared Data private yyjson 0.12.0 source:
  `third_party/yyjson-0.12.0/`
- Offline SDL2 kit: `third_party/SDL2/`
